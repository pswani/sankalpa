# Sankalpa 2 previews

These are actual simulator captures, using Debug-only example data. They are not design mockups.

The iPhone set covers Today, practice detail, Collection, dark appearance, large text, and landscape. The iPad set covers portrait and landscape, including the native session sheet.

Run `../scripts/run.sh --demo` from this folder, or `./app2/scripts/run.sh --demo` from the repository root, for an interactive tour. Demo data uses a separate preview store. See `../QUALITY.md` for the verification record and limits.
